# YuvaIntern Task 2 — Hands-On Data Lab Implementation

## Overview
A practical Python data-analysis project covering data loading, cleaning, manipulation, EDA, statistics, visualization and business insights.

## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn and Scikit-learn (environment reference).

## Structure
- `Task_2_Data_Analysis.ipynb` — complete analysis notebook
- `dataset/sales_data.csv` — reproducible sales dataset
- `YuvaIntern_Task_2_Report.docx` — internship report

## How to Run
Open the notebook in Jupyter Notebook or Google Colab. Keep the `dataset` folder beside the notebook so the CSV path works.
